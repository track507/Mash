# Grim Hollow (2024 sheet)

- [Playtest Pack v0.1](https://github.com/track507/Mash/raw/main/2024/Grim-Hollow/Playtest_Pack_v0.1.js) - Grim Hollow: Transformed playtest content (Wrathful Dead, College of Fools, Purification Domain)

The 2014 scripts are in the [2014 Grim Hollow folder](../../2014/Grim-Hollow/README.md).

## How to use

1. Download the script: open its link below, or right-click the link and choose "Save link as"
2. Open the MPMB character sheet in Adobe Acrobat
3. Use the **Add Extra Materials** bookmark and import the downloaded file
4. The content appears in the sheet's menus
