# Ariadne's Codex of Strings

These are scripts for MPMB's Character Creation sheet.

They add items, subclasses, classes, and more to the sheet from [Ariadne's Codex of Strings](https://www.patreon.com/codexofstrings/posts).

## Which script to import

Import either the whole-book Codex or individual book files.
Do not combine the Codex with individual book files, because it holds the same content and will cause errors.

[Ariadne's Codex of Strings](https://github.com/track507/Mash/raw/main/2014/Ariadne/Ariadne%27s%20Codex%20of%20Strings.js) holds the content of the 13 book files marked "In the Codex" below.
The deluxe versions take priority over their initiate counterparts.
It does not include The Shaper V2, The City of Strings or Better Items V3, so import those separately.

Since spells don't have specified classes, all classes are assumed to get them.
