# WotC add-ons

Additions to official books for the MPMB character sheet.

## Fizban's Treasury of Dragons: Draconic Gifts

[FToD_Draconic_Gifts.js](https://github.com/track507/Mash/raw/main/2014/WotC-Addons/FToD_Draconic_Gifts.js) contains the Draconic Gifts from FToD.

These gifts are coded as feats, except for Draconic Rebirth which is coded a race.
The code for Draconic Rebirth is the same as the Chromatic, Gem, and Metallic dragon's implementation, with some minor changes to allow for skills to be carried over.

This script does not contain a source and is meant to be used with either "All Official WoTC 5e Content" or "Fizban's Treasury of Dragons" found in [MPMB's Index](https://docs.google.com/spreadsheets/d/15xq5gP3MujE7nc7POGngFWKLhabkun9BoUW7vvrhkTY/edit#gid=782534184).

## How to use

1. Download the script: open its link below, or right-click the link and choose "Save link as"
2. Open the MPMB character sheet in Adobe Acrobat
3. Use the **Add Extra Materials** bookmark and import the downloaded file
4. The content appears in the sheet's menus
